## 2. 开测前准备（乙做一次，约 10 分钟）

1. **建账号**：乙登录 → 「成员管理 → 新增成员」建 `test_admin`（生活委员）、`test_member`（普通成员）。
   院长号 `dean` 已建好（纯院长）；要再开一个用「学院 → 院长账号」页。
2. **造数据**（没有数据测不出东西）：
   - 1 个班、**至少 8 名学生**（学院名册页下载模板 → 填 8 行 → 导入，**带上「年级」列**）
   - 类别：启动时已自动铺 11 条，不用建
   - 班主任（乙）**不在**缴费名单里，缴费对象是 8 名学生 + 丙 + 丁
3. **每人先做一次**：登录 → 个人信息 → 改一次密码再改回来（测会话）。
4. 每台设备只登一个号，避免串号。

## 3. 分功能用例

### 甲 — 院长（学院层）

| 编号 | 操作 | 预期 | 结论 |
|------|------|------|------|
| A1 | 登录 | 侧栏出现「学院」分组：班级管理（学生名册 / 班主任名册 / 院长账号）、任务（学院任务 / 班级任务 / 任务总览） | |
| A2 | 学生名册 | 跨班看到全部学生；按班级 / 年级 / 关键词筛选有效；分页正常 | |
| A3 | 下载模板 | 表头前 4 列 = **班级 / 年级 / 学号 / 姓名**，「年级」只有一列 | |
| A4 | 导入带「年级」的名单 | 提示 `已按名单里的『年级』补上：…`；**班主任名册的年级列**跟着变（不是空的） | |
| A5 | 导出（只勾学号+姓名） | 表头**一定有**学号/姓名；没勾的班级/年级**不出现** | |
| A6 | 改一格（如专业名称）→ 刷新 | 改的值还在；改一个**不存在的字段** → 报错，不静默丢弃 | |
| A7 | 转班：把学生调到另一班 | 班级变了，**原有值一个不丢**；调回原班同样正常 | |
| A8 | 班主任名册 | 默认排序：**年级新→旧、同年级按班名**（大数据2401…2403 → 检测2401…2406 → 计科2201班）；一行一班 | |
| A9 | 名册勾选 2 个班删除 | 有学生的班**跳过并逐条说明原因**（「班里还有 N 名学生」），空班删掉 | |
| A10 | 新增班主任（选班+姓名+登录名） | 建完**当场占位**（名册显示该人）；同班再建一个 → 报「一班一位」 | |
| A11 | 改班主任安排 | 换人 = 顶替；清空后该班显示「未登记」 | |
| A12 | 学院任务：发布一条 `BOOLEAN` + 截止 + 置顶 | 乙在「学院任务」里能看到并**逐个点名应答**；丁看不到（只有班主任答） | |
| A13 | 任务总览 | 总条数、开放中、**回收率**、按班 / 按发布人分布与实际一致 | |
| A14 | 关闭一条**已过期**的任务 → 重开 | 弹「同时延长截止」；**只重开不给新截止 → 仍显示已关闭**；给过去的截止 → 报错 | |
| A15 | 导出任务明细 Excel | 能下载，内容与看板一致 | |
| A16 | 手输 URL `/member-manage`、`/income` | **纯院长进不去**（无入口 / 403），侧栏也不显示 | |

## 4. 通过标准

- §3 全部 ✅，无 ❌ → 功能可交付。
- 出 ❌：记下**编号 + 账号 + 一步复现**，按 §5 报。
- **重点盯这几条**（最近改过，最容易回归）：
  - `A9` 删班级（类别不再挡路）、`A10` 新增班主任、`A14/B15` 重开延截止、`A4` 导入识别年级、`A8` 名册排序。
