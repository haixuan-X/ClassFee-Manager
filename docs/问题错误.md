# 重点：任务、账目、数据不能串

- 等级：`普通成员 0 < 生活委员 1 < 班长 2 < 班主任 3 < 院长 4`。

## 院长账号：

### 1.总览：

- [ ] 功能是否正常，有误页面报错。
- [ ] 学生数据是否能对上。
- [ ] 学籍变化是否能正常使用。

### 2.学院：

- [ ] 院长账号是否能正常创建

#### 2.1班级管理：

##### 学生名册：

- [ ] 导入导出是否正常识别，导出模板是否正确，导入新字段时是否自动添加。
- [ ] 添加字段、删除字段、停用字段、恢复字段是否正常。
- [ ] 搜索、筛选功能是否正常。
- [ ] 页面分页是否正常。

##### 班主任名册：

- [ ] 导入导出是否正常。
- [ ] 新增班主任，改班主任安排是否正常，有误报错。
- [ ] 批量选中删除是否正常。

#### 2.2任务

##### 任务总览：

- [ ] 数据是否识别正确，数据是否正确。
- [ ] 导出功能是否正常、导出数据是否正常。

##### 学院任务

> 排错流程：院长发布任务 --> 班主任填写 --> 院长查看数据是否正常

- [ ] 发布功能是否正确、是否能发布任务。
- [ ] 搜索是否正常，筛选。
- [ ] 班主任填写之后数据是否正确。
- [ ] 操作详情、导出、编辑、关闭、置顶、删除功能是否正常。

##### 班级任务：

> 排错流程：班主任发布任务 --> 院长查看任务状态是否正常

- [ ] 任务数据是否正常
- [ ] 搜索筛选框是否正常

##### 个人信息：

- [ ] 账号切换是否正确
- [ ] 修改账号信息是否正常
